spec.md .dawsha/runs/r-0412/spec.md

Goal

Let people save the Usage table as a CSV file for a chosen date range.

Acceptance criteria

  1. An Export CSV button sits in the Usage view header.
  2. The dialog offers Last 7 days, Last 30 days, This month and Custom range.
  3. Columns: date, project, agent, model, input tokens, output tokens, cost (USD).
  4. The file is named dawsha-usage-YYYY-MM-DD.csv and opens cleanly in Excel (UTF-8 with BOM).
  5. When the range has no usage, the dialog says so and the Export button is disabled.
Your comment on v1: "add a 'group by project' option, the lead wants totals" → added as criterion 6 in v2.
  1. A "Totals per project" checkbox adds a summary block at the end.

Edge cases

  • Agents with no cost data (Codex, Gemini, local) export cost as empty, not 0.
  • Very large ranges are written in chunks without freezing the UI.

Out of scope

  • Scheduled or emailed exports.

Open questions

  • Should costs use your price settings for non-Claude models? → sent to Human review
