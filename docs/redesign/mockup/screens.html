Arabic and RTL

What changed. A written rule instead of partial mirroring (15). Layout follows the app language; text follows its own script. Left shows an English app with Arabic content, right shows the app set to Arabic.

Before: sidebar
The rule
  1. Chrome mirrors only when the app language is Arabic: dir="rtl" on the window, logical properties everywhere, and icons that point (chevrons, back, panel toggles) flip. Logos, play and media icons do not.
  2. User content decides its own direction: every title, prompt and note uses dir="auto", so an Arabic session title aligns right inside an LTR sidebar and truncates at its own end.
  3. The terminal grid stays LTR. Arabic lines are shaped by the terminal, with Latin identifiers, paths and numbers kept intact.
  4. Numerals stay Western and tabular. Arabic text uses IBM Plex Sans Arabic at the same size steps.
