Foundation

Sessions grid

What changed. A session that needs you now takes space and shows exactly what it is asking: the tool, the command and the file it writes, with Allow, Allow always and Deny at the point of action (audit 1). Needs-you is an orange edge, a tinted header and a slow pulse that stops under reduced motion, and the grid reflows around it (2, 3). Every pane header has the same four slots, so the state chip always sits in the same place (4). Pick a direction and a pane count, click a sidebar session, open a pane menu, or press Allow (or Enter).

Before: 3 panes Before: 5 panes
keyboardEnter allows, Esc denies the pane that needs you

A, Calm focus. One pane is the focus and gets the room. Siblings are quiet: no footer, a short tail of output, lower chrome. A sibling that needs you promotes itself to a tall card in the column so you can answer without moving focus. Best for one main task with helpers.

B, Mission control. Equal tiles, each with the same anatomy, so a scan across the grid reads state only. Needs-you is the one tile with a full orange edge, a tinted header and the approval card. Best when you babysit three to six agents at once.

Pane anatomy

What changed. The header holds a state chip and three buttons; everything else is in one grouped overflow menu of 12 items instead of 22 flat ones (4). The footer is model, branch, diff stats and a visible Review button; "Turn on live info" moved into the Info panel as a real toggle (3, 6). Info, Timeline, Tasks and Changes slide over the terminal instead of squeezing it, and the Timeline starts with one filter row instead of seven control rows. Use the panel button and the tabs.

Sidebar

What changed. Rows now say what the session is doing instead of "Idle . now": the title, then the live activity, with the state on the agent mark itself (12). Needs-you has its own block above everything. The missing folder is flagged in the list with a Locate action, projects have a right-click menu, and menus anchor to the row without covering its neighbours. Hover a row for its menu, right-click a row or project, collapse a project, click a row to focus its pane.

A, Project tree

Projects first, sessions inside, like a file tree. Familiar, and right when you work project by project.

  • checkCollapsible projects with branch and a needs-you hand on the header
  • checkMissing folder keeps its place with Locate
  • checkCompact rail: project initials, then session marks

B, By attention

Sessions grouped by what they need from you, with the project as a filter chip. Best when you run many sessions across projects.

  • checkNeeds you, Working, Ready to review, Idle, in that order
  • checkOne-line project filter instead of nested folders
  • checkCompact rail follows the same order, so it doubles as a status strip

Top bar and usage

What changed. The bar has 11 targets instead of 17: logo, five pages, one usage strip, search, bell, settings and New session (8). Grid and Board, Layouts, Dim others and text size moved into the sessions toolbar where they apply. The active page is always highlighted, and Projects, Usage and Agent tools no longer hide under a "More" tab; "Agents" is now "Crew" so it cannot be confused with Skills or the CLI installer (7). The usage strip opens a popover with the same numbers as the Usage page, including the reset time (8). Click a page, click the strip.

Empty app and first run

What changed. Onboarding is one dialog in the shared shell with three steps you can read: done, current and upcoming steps all pass 4.5:1 instead of fading to 2:1, and the disabled Start button says why (11, 15). The empty app uses the one empty-state pattern: title, one sentence, one primary action and the shortcut.
