A chat view for sessions

The same session, shown as a conversation. The agent keeps running in its terminal, and each session can switch between the two at any time. Pick a direction and try the states. The conversation is example data; the styling is Dawsha's own.

The default lives in Settings, and New session can override it. A session remembers its choice when it resumes.

How it would work

The terminal stays the source of truth. Chat reads the agent's session log, which Dawsha already watches for status, and draws it as messages. What you type goes to the same terminal, so nothing about how the agent runs changes.

Approvals reuse today's card. Dawsha already detects them from the terminal output, and Allow and Deny send the same keys as now.

Terminal stays one click away, because anything chat can't draw, such as a menu or a slash-command screen, needs it. Chat says so and offers the switch.

What's harder than it looks

Three different agents. Claude, Codex and Gemini each write their logs differently, so each needs its own reader. I'd do Claude first and leave the setting disabled for the others until theirs is ready.

Log formats can change in any CLI update. When a reader fails, chat should fall back to the terminal and say why, without losing the session.

Live text. Logs usually arrive a message at a time, so replies may appear in chunks and not word by word. I haven't tested this on each agent yet.

Effort: my rough estimate is medium for Claude, then small to medium per extra agent.
