Files navigation, like VS Code

A working mock of the Files view. Pick a direction, click a name in the code, then press F12 or Ctrl+F12. The code is example data; the colours, fonts and layout are Dawsha's own.

What I need from you

  1. Direction. I recommend Jump first, because it is what VS Code does: one result jumps, several open a peek.
  2. C#. I recommend using csharp-ls when it is installed, with a one-click install offer and search by name until then. Nothing that answers Ctrl+F12 for C# is small enough to bundle.
  3. Which of the extras to include in the first round. The table below marks my pick.

How the keys get answers

Search by name, for every language. Instant and offline, with no download. It finds definitions well and guesses at implementations, so those results say "Best match by name".

TypeScript and JavaScript. The TypeScript service ships with the app, adding about 2 MB to the installer. It gives exact answers once it has started, which can take 2 to 10 seconds and use 300 MB to 1 GB of memory in a big repo.

C#. Uses csharp-ls or OmniSharp if found. A large solution can take 10 to 60 seconds to load, and name search covers that time.
