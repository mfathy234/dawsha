Dawsha, unslopped

The 1.8.0 build checked against the unslop guides: an audit of where the app still slips, then three screens redrawn with the fixes. Switch each screen between Before, After and Compare.

Verdict Light slop. Polish mode
Kept Geist and JetBrains Mono, the near-black ramp, the mint brand color, every feature and layout
Changed Where color goes, weights and sizes, a few labels, the attention state

Direction

Five lines, taken from what Dawsha does. Every fix below follows from them.

Product
One window where a developer runs and watches several AI coding agents in readable terminals
Character
Watchful, exact, quiet until it needs you
World
A control room on the night shift. Terminals, status lamps and one light that comes on when someone has to act
Moments
The approval card, which shows what the agent wants to run, and the usage chart
Signature
The state lamp. A spinning ring for working, an amber diamond for needs you, a mint tick for done, a hollow dot for idle. Same glyph in pane headers, sidebar rows and the board, nowhere else
