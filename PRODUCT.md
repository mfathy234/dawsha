# Product

## Register

product

## Users

Software developers who run Claude Code, Codex CLI, and Gemini CLI in parallel across local projects. They need to see each agent's session and status, switch tasks quickly, and resume work without losing context.

## Product Purpose

Dawsha brings local AI coding agents into one desktop workspace with readable terminals, clear session state, and direct project navigation. Success means users can move between agents and projects without losing track of what is running or waiting for them.

## Brand Personality

Focused, technical, and low-friction. The interface should feel dependable and quick, with plain language and useful feedback.

## Anti-references

Avoid dated desktop controls, crowded toolbars, decorative UI that competes with terminal work, and generic AI-dashboard conventions.

## Design Principles

- Keep agent sessions and their status at the center of the workflow.
- Make navigation and common actions direct and easy to find.
- Use clear labels and visible state instead of relying on hidden behavior.
- Keep work and agent data local to the user's machine.
- Preserve keyboard access and familiar platform conventions.

## Accessibility & Inclusion

Support keyboard navigation and shortcuts, visible focus, readable contrast across themes, and reduced-motion preferences. Do not rely on color alone to communicate session state.
