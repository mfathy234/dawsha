Sessions board

Switch the grid to a board with four columns: Needs you, Working, Done to review and Reviewed. Cards move by themselves as sessions change.

  • Allow or Deny a permission prompt right on the card.
  • Click a card to peek at the live terminal and send a reply.
  • Drag a finished session to Reviewed, or close all reviewed sessions at once.
  • Filter by project and agent. Ctrl+Shift+B switches between the board and the grid.

Session timeline

Every prompt, edit, command and test run of a session in one list, with insights on the files touched most and how the test runs went.

  • Filter by Prompts, Edits, Commands, Tests or Approvals, and search inside the session.
  • Click an edit to see exactly what changed.
  • Export the timeline as Markdown. Ctrl+Shift+T opens it.

Search every session, even closed ones

Ctrl+Alt+F searches the prompts, replies, edits and commands of all your sessions, including ones you closed days ago.

  • Matches are grouped by session, with the agent, project and date.
  • Open a match read only at the exact point, or resume the session from there.
  • Narrow the search by project, agent or kind of event.

Replay

Watch a recorded terminal play back like a video. Recording is off until you turn it on in Settings, and recordings never leave your computer.

  • Jump between markers for prompts, permission requests and the end of the session.
  • Search the recording and jump to a match.
  • Skip idle time, play at 4x or 16x, or copy the text on screen.
  • Choose how long to keep recordings and how much disk they may use, and pause recording per pane. Open Replay from the pane header or the timeline.

Your agents, in your pocket.

Step away from your desk and keep going. Turn on Remote Access in Settings, open the link on your phone and enter the pairing code. Your sessions keep running on your computer.

  • The real terminalClaude Code and Codex redraw at your phone's size, so tables, code and prompts line up.
  • Approve from your phoneThe Approvals tab lists every session waiting on you. Allow once, or Deny with a reason the agent reads. Notifications arrive while the page is open.
  • Safe by defaultOnly a plain Yes can be allowed from the phone. Edits to CI, config, .git and .claude files can only be denied; open Dawsha to allow them.
  • Reply from anywhereType a message and send it. Esc, the arrow keys, Tab, Enter and Ctrl+C are one tap away for menus and approvals.
  • Start or resume sessionsOpen a new session in any project, or pick up a recent one.
  • You set the limitsPaired browsers start read only. Allow typing and session control separately, and revoke a browser at any time.
  • Private linkTraffic goes through a temporary Cloudflare Quick Tunnel. Add an email PIN for a second gate.

How it works

  1. 1

    Install

    Run the installer or the portable exe. Sign in once to each agent CLI you use, in any terminal.

  2. 2

    Add projects

    Pick a folder and a default agent. A short first-run setup shows which CLIs it found.

  3. 3

    Start sessions

    Press Ctrl+N, or run dawsha . in a folder. Each agent runs in its own terminal.

  4. 4

    Stay on top

    Glance at status, plans and context. Come back when a session needs your input.

The dawsha command

The installer adds it to your PATH. Open a new terminal and drive Dawsha from where you already work.

# add this folder and start its agent
dawsha .

# start a specific agent on a project
dawsha start billing-api --agent codex

# pick up the newest session
dawsha resume --last
